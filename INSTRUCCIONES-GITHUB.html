🚀 Subir Rompelímites a GitHub

Guía paso a paso — 5 minutos de tu tiempo

⚡ Opción Rápida (Terminal)

1

Verificar Git

Abre terminal/cmd y ejecuta:

git --version

Si no sale nada, descarga: https://git-scm.com

2

Ir a la carpeta del proyecto

cd rompelimites-bookstore
3

Ejecutar script de deploy

Reemplaza TU_USUARIO con tu usuario GitHub:

bash deploy.sh TU_USUARIO

Ejemplo:

bash deploy.sh miguelmartosrompelimites
⚠️ Cuando pida contraseña:
No uses tu contraseña de GitHub. Usa un Personal Access Token:
  1. Ve a: github.com/settings/tokens
  2. Click en "Generate new token (classic)"
  3. Nombre: "GitHub Pages Deploy"
  4. Selecciona ✅ repo y ✅ workflow
  5. Copia el token y pégalo en terminal (no verás caracteres)
4

Activar GitHub Pages

  1. Ve a: https://github.com/TU_USUARIO/rompelimites
  2. Click en Settings (esquina superior derecha)
  3. En menú izquierdo: Pages
  4. Source: Selecciona main
  5. Folder: Selecciona / (root)
  6. Click en Save
✅ ¡Listo!
Tu web estará en vivo en:
https://TU_USUARIO.github.io/rompelimites
(Espera 2-3 minutos a que GitHub construya)

📝 Opción Manual (GitHub Web)

1

Crear repositorio en GitHub

  1. Ve a: github.com/new
  2. Repository name: rompelimites
  3. Description: Tienda digital de libros
  4. Selecciona: ⚪ Public
  5. NO marques "Initialize with README"
  6. Click en Create repository
2

Subir archivos (Drag & Drop)

  1. En la página del repo, verás un área gris
  2. Arrastra todos los archivos de rompelimites-bookstore/
  3. Commit message: Tienda digital Rompelímites v1.0
  4. Click en Commit changes
3

Activar GitHub Pages

  1. Click en Settings
  2. En menú: Pages
  3. Source: main
  4. Folder: / (root)
  5. Click en Save
✅ ¡Hecho!
Verás: "Your site is published at..."
Abre tu web en 2-3 minutos.

🖥️ Opción GitHub Desktop (GUI)

1

Descargar GitHub Desktop

Descarga desde: desktop.github.com

2

Inicializar repositorio

  1. Abre GitHub Desktop
  2. File → Add Local Repository
  3. Selecciona carpeta: rompelimites-bookstore
  4. Click en Create Repository
3

Publicar a GitHub

  1. Click en Publish repository
  2. Name: rompelimites
  3. Description: Tienda digital de libros
  4. Selecciona: ⚪ Public
  5. Click en Publish Repository
4

Activar Pages (web)

  1. Ve a: https://github.com/TU_USUARIO/rompelimites
  2. Settings → Pages
  3. Source: main
  4. Folder: / (root)
  5. Click en Save
✅ ¡Completado!
Tu sitio estará en vivo en 2-3 minutos.

❓ Preguntas Frecuentes

❌ "Error: Permission denied"

Solución: Usa Personal Access Token (no contraseña)

  1. Ve a: github.com/settings/tokens
  2. "Generate new token (classic)"
  3. Selecciona ✅ repo y ✅ workflow
  4. Copia y pégalo en terminal cuando pida contraseña

❌ "Repository not found"

Verifica:

  • Tu usuario GitHub sea correcto
  • Hayas creado el repo en GitHub
  • Estés en la carpeta rompelimites-bookstore

❌ "Página en blanco o 404"

Solución:

  1. Ve a: GitHub repo → Settings → Pages
  2. Verifica: Source = main, Folder = / (root)
  3. Espera 5 minutos más
  4. Limpia caché: Ctrl+Shift+R (Windows) o Cmd+Shift+R (Mac)

❌ "Los estilos no cargan"

Solución: Abre consola (F12) y revisa rutas. En GitHub Pages a veces necesitas ./assets/ en lugar de /assets/

✅ ¿Cuánto tiempo tarda?

GitHub construye tu página en 1-3 minutos. Si no ves cambios, espera más y limpia caché.

✅ ¿Cómo editar después?

Opción 1: Edita en GitHub web (archivo → ✏️ → commit)

Opción 2: Edita localmente y: git add . && git commit -m "..." && git push

✅ ¿Puedo usar dominio propio?

Sí. Compra dominio (GoDaddy, Namecheap, etc.) y en Settings → Pages agrega "Custom domain"

💡 Tip: Si algo falla, revisa la consola (F12) o usa GitHub Desktop para más control visual.
