⚡ OPCIÓN RÁPIDA: SUBIR A GITHUB EN 5 MINUTOS
═══════════════════════════════════════════════════════════════════════════

Paso 1: Abre terminal/cmd
Paso 2: Ve a la carpeta:
        cd rompelimites-bookstore

Paso 3: Ejecuta (reemplaza TU_USUARIO):
        bash deploy.sh TU_USUARIO
        
        Ejemplo:
        bash deploy.sh miguelmartosrompelimites

Paso 4: Cuando pida contraseña, usa Personal Access Token:
        - Ve a: github.com/settings/tokens
        - Crea token con permisos: repo + workflow
        - Pégalo en terminal

Paso 5: Ve a GitHub → Settings → Pages
        - Source: main
        - Folder: / (root)
        - Save

✅ ¡LISTO! Tu web estará en:
   https://TU_USUARIO.github.io/rompelimites
   (Espera 2-3 minutos)

🎨 PERSONALIZAR TUS LIBROS

   Edita: assets/css/style.css

❓ PREGUNTAS FRECUENTES
═══════════════════════════════════════════════════════════════════════════

P: ¿Necesito saber programación?
R: No. Solo necesitas copiar/pegar datos en app.js

P: ¿Cuánto cuesta?
R: Gratis. GitHub Pages es gratuito.

P: ¿Puedo usar mi dominio?
R: Sí. Después de activar Pages, agrégalo en Settings.

P: ¿Cómo agrego mis propias portadas?
R: Copia imágenes a assets/img/portadas/ y actualiza app.js

P: ¿Se puede integrar Stripe?
R: Sí, pero necesitas backend (Node.js, Python, etc.)

P: ¿Mi web será segura?
R: Sí. GitHub usa HTTPS automáticamente.
